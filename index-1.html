Publish ke Domain Gratis

Cukup simpan file index.html ini lalu unggah ke salah satu layanan gratis berikut:

1. Netlify Drop (Paling Cepat - 30 Detik)
• Buka app.netlify.com/drop di browser.
• Tarik/unggah file index.html ini.
• Langsung dapat link gratis https://nama-unik.netlify.app!
2. Tiiny.host (Bisa langsung dari HP)
• Buka tiiny.host di Chrome/Safari HP kamu.
• Pilih file index.html, ketik nama subdomain, lalu klik Publish!
3. GitHub Pages / Vercel
• Upload index.html ke repository GitHub, aktifkan GitHub Pages untuk domain .github.io selamanya.
